Install

Claude Code

Add the marketplace once, then install the bundle or a single skill.

/plugin marketplace add {{REPO}}
/plugin install ethical-skills@{{MARKETPLACE}}

Claude apps

Download the zip of one skill below. In Claude, open Settings, find Skills, and upload the zip.

By hand

Unzip into your skills folder. Each skill is one folder with a SKILL.md inside.

unzip ethical-skills-all.zip -d ~/.claude/skills/

After you install fetch-rules, open its SKILL.md and put your own name and contact address in the User-Agent line. Server admins use it to reach you.
